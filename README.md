# sidenote（サイドノート作成ツール）

🔗 https://sidenote-tool.pages.dev/

## このツールについて

- テキスト・スクリーンショット・Markdown・PDFなどの資料に、右側のサイドノートで注釈を付けていくツールです。
- 左＝本文（テキスト・Markdown・画像、またはPDF本体）、右＝サイドノート、の2カラム構成です。
- **本文のデザインは7種類（エディトリアル／文書＝ミニマル／フラット／ダークUI／和モダン／サイト／2段組）から、いつでも切り替えられます。** 中身（テキスト・注釈）は変わりません。「2段組」は和モダンをベースに、PDFを「2ページ/枚」（A4縦の2ページを1枚に左右に並べる印刷。ツールの外で行います）にしても読めるよう、サイドノートなしのPDFの本文を12pt→14pt（割り付け後に9〜10pt）、見出しを比例して拡大、1行を34字にしたデザインです（用紙・段数はA4縦・1段のまま。サイドノートがある文書は従来のサイドバー付きの版面になります）。
- **書式ツールバー（配置・インデント・ぶら下げ・太字・下線・傍点・スタイル）と「項番設定」（見出しの見た目、項番の型ごとのインデント・ぶら下げの一括適用）**で、準備書面のような書面の体裁を整えられます（デザインパネルの「カスタマイズ」から開きます）。
- **「開く」で既存のPDFファイルを選ぶと、そのPDFに直接サイドノートを付けるモードになります。** 文字が選択できるPDFは範囲選択、スキャンなど文字が選択できないPDFはクリック／ドラッグでノートの位置を指定します。
- 見出し・段落・太字/斜体・リンク・リスト・引用・表・区切り線・コードブロック・画像など、基本的なMarkdown構文の取り込み・書き出しに対応しています。Wordのような改ページも、HTMLコメントの1行 `<!-- pagebreak -->`（またはツールバーの「改ページ」ボタン）で入れられ、PDF化とWord書き出しでその位置から次のページになります。
- **処理はすべてブラウザ内で完結し、内容はサーバーに送信されません。**
- 注釈済みの範囲は編集できなくなるため、元の文章を誤って書き換える心配がありません。
- 公開は Cloudflare Pages を利用しています。
- 2026-09、sidenote-pdf（注釈専用のシンプル版）・sidenote-pdf-doc（書面レイアウト版）をこのアプリへ統合し、両者は廃止しました。

## 使い方

1. 左側に本文となる文章を貼り付ける（スクリーンショットは Ctrl+V での貼り付け、段落にカーソルを乗せて出る「＋画像」、または書式ツールバーの「画像を挿入」から挿入。画像はdata URLとして本文に持つので、Markdownで書き出すと `![](data:image/png;base64,…)` になります）。AIチャットのMarkdownをコピーして貼り付ければMarkdownとして取り込まれます。「開く」から.md・.pdf・.jsonのいずれかを選ぶこともできます。
2. 注釈したい一文・画像・表を選択すると入力欄が出るので、コメントを書いて色（自分／共有相手／重要）を選ぶ。
3. 同じ範囲に複数人でやり取りしたい場合は、サイドノートの「＋ 返信」で追記できる（返信スレッド）。
4. 段落・画像・表・区切り線・改ページはJIMDOのようなブロック単位の操作で、段落にカーソルを乗せると出る「×」でその1ブロックだけ削除できる。
5. 準備書面などの体裁を整えたい場合は、書式ツールバー（配置・インデント・ぶら下げ・太字・下線・傍点・スタイル）と「デザイン」→「カスタマイズ」の項番設定を使う。
6. 作業内容はブラウザに自動保存される。日をまたいで再開する場合は「続きから再開」。
7. 区切りの良いところで「保存」（.jsonファイルに書き出す。画像・PDF本体も内包した1ファイル。共有相手はこのファイルを「開く」で開いて注釈を追記できる）。
8. .mdを少し直しただけの時は「MDで書き出す」（注釈は含まれないプレーンなMarkdownとして書き出す。PDFモードでは使えません）。
9. 印刷・共有用には「.pdf」（カラー／白黒を選ぶと印刷ダイアログが開くので、保存先で「PDFに保存」を選ぶ）。白黒は文字を黒・画像を灰色にして書き出します。

## 仕組み（ブラウザ完結）

- Markdownの取り込みは `public/md-parser.js`（依存ライブラリ無しの自前パーサー）が担当し、見出し・段落・引用・水平線・表・リスト項目・コードブロック・画像のブロック配列に分解します。逆方向（本文DOM→Markdownテキスト）は `public/app.js` の `docToMarkdown()` が担当し、「MDで書き出す」で使われます。注釈・書式（配置・インデント等）は書き出しに含まれません。
- 本文は`contenteditable`の段落（`.para`）単位で管理し、注釈した範囲は`contenteditable="false"`にしてロックします（原文の改変防止）。配置・インデント・ぶら下げ・スタイルは`data-*`属性で持たせ、画面・印刷（PDF化）の両方がこの属性から表示用のスタイルを組み立てます。
- PDFモードはPDF.js（`public/vendor/pdfjs`、Apache License 2.0）で既存PDFをcanvasに描画し、テキストPDFは範囲選択、スキャンPDFはクリック／ドラッグでノートの位置（ページ空間座標）を記録します。元PDFはdata URLとして`.json`にそのまま内包します。
- デザイン（テーマ）は `public/themes.css` の7種類のCSS変数セットを`<html data-theme="...">`経由で切り替えるだけで、本文のDOM自体は変わりません。
- 1つの注釈範囲（アンカー）には複数のノートを配列で持たせており、返信スレッドとして追記できます。色は黒＝自分／青＝共有相手／赤＝重要の3色です。
- 保存（.json）はタイトル＋日時付きファイルに書き出します。画像・PDF本体はdata URLとして内包するため1ファイルで完結します。あわせてlocalStorageへの自動保存もあり、次回起動時に「続きから再開」で復元できます。
- 保存（.pdf）は独自のPDF生成ライブラリを使わず、ブラウザ標準の印刷機能（印刷用CSS＋`window.print()`）を利用します。本文モードはサイドノートを段落の隣にfloatで配置するTufte CSS方式、PDFモードはページ画像に対する絶対座標で配置します。「.pdf」ボタンで白黒を選んだ時は、印刷版面の画像をCanvasで灰色に変換（`convertPrintImagesToGray`）し、bodyに`.print-bw`を付けて文字・線・サイドノートの色を黒にしてから印刷します。
- React / Next.js は使用していません（素のHTML＋バニラJSで実装しています）。
- アイコンは Bootstrap Icons（MIT License）から使う分だけSVGをそのまま埋め込んでいます。デザイン用の書体は Google Fonts から読み込んでいます。詳細は [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) を参照してください。

## ファイル形式の使い分け

- **.md**：AIチャット等が出力したMarkdownの取り込み用（本文を丸ごと置き換える）。「MDで書き出す」で逆方向（本文→.md）にも書き出せますが、注釈・書式は含まれません。
- **.json**：作業の続きの保存・共有相手とのやり取り用（双方向。相手も「開く」で開いてノートを追記できます。注釈・書式・元PDFも含む）
- **.pdf**：印刷用、またはjsonでのやり取りに不慣れな相手向け

## ローカルで動かす

```bash
npm install          # wrangler を入れる
npm run dev           # http://localhost:8788 で確認
```
`python -m http.server -d public 8000` でも構いません。

## 公開（Cloudflare Pages）

```bash
npm run deploy       # wrangler pages deploy
```
本人・関係者限定にする場合は、Cloudflare Access（Google ログイン）を前段に設定してください。

## 運用上の注意

- 保存した`.json`（画像・PDF本体を内包）には、注釈対象の資料そのものが含まれます。**個人情報・機微情報を含むファイルはコミット・pushしないでください。**
